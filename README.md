# 線香花火

色を仕込んで、自分だけの線香花火を一本燃やすミニゲームです。
スマホのブラウザでそのまま遊べます。

**遊ぶ → https://konbu-love.github.io/senko-hanabi/**

## 遊び方

1. こよりの左右に並んだ丸に触れて、色を仕込みます(2列×5段、6色)。
2. 「火をつける」を押します。
3. 火は下から上へ昇り、通った段の色を混ぜながら燃えていきます。
4. 最後は小さな玉になって、水面に落ちて消えます。一本およそ30秒です。

「おまかせ」を押すと、色をランダムに仕込めます。
音が出ます。「音 あり／なし」で切り替えられます。

## 五つの段

本物の線香花火の移り変わりに合わせて、段ごとに燃え方が変わります。

| 順番 | 名前 | 燃え方 |
| --- | --- | --- |
| 1 | 蕾(つぼみ) | 火の玉がふくらむ |
| 2 | 牡丹(ぼたん) | 大きな火花がひとつずつ弾ける |
| 3 | 松葉(まつば) | 枝分かれした火花が四方へ広がる |
| 4 | 柳(やなぎ) | 長く尾を引いてしなだれる |
| 5 | 散り菊(ちりぎく) | 細い火花がぽつぽつと消えていく |

火花はその段に仕込んだ2色で弾け、通ってきた段の色も少し混ざります。
